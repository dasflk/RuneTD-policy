# Drop Rates

[한국어](./probability-ko.html)

This page discloses the items and odds of every draw ticket in Tower Battle. The odds below match how the game server actually draws.

- Last updated: November 1, 2026

---

## 1. Draw Tickets

| Ticket | Purchased with | Type | Possible results |
|---|---|---|---|
| Rune Ticket | Gems (paid currency) | Paid randomized item | 41 runes |
| Normal Ticket | Coins (free currency earned by playing) | Free randomized item | 24 skins or 41 runes |

## 2. General Rules

- A 10x draw has exactly the same odds as ten single draws. Every draw is independent.
- There is no pity system: odds never change with the number of draws, and no item is guaranteed.
- All runes have the same odds regardless of their grade. Result animations have no relation to the odds.
- Any tickets given for free in the future (for example, in events) will use the same odds.
- Percentages are rounded to three decimal places, so totals may differ slightly from 100%. Exact odds: 1/41 per rune for the Rune Ticket; 1/48 per skin and 1/82 per rune for the Normal Ticket.

## 5. Duplicates

- **Skins**: If you draw a skin you already own, you receive **30 Coins** instead. If the same new skin appears more than once in a single 10x draw, the first one is given as the skin and each extra copy is converted to 30 Coins.
- **Runes**: A rune you do not own is added to your collection. If you draw a rune you already own (including a second copy within the same 10x draw), that rune gains **1 upgrade XP**. Runes are upgraded as XP accumulates, as shown below.

| Upgrade | Required XP | Cumulative XP |
|---|---|---|
| +0 → +1 | 3 | 3 |
| +1 → +2 | 3 | 6 |
| +2 → +3 | 3 | 9 |
| +3 → +4 | 3 | 12 |
| +4 → +5 | 5 | 17 |
| +5 → +6 | 5 | 22 |
| +6 → +7 | 5 | 27 |
| +7 → +8 | 7 | 34 |
| +8 → +9 | 7 | 41 |

- The maximum upgrade level is +9 (41 cumulative XP). Duplicates drawn after reaching the maximum level have no further effect.

## 6. Changes to Odds

If we change the odds or the item pool, we will post it on this page before the change takes effect, and also mention it in the store update notes if an app update is released in the meantime.
